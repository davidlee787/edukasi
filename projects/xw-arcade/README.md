# XW Edukasi Arcade

**Status:** Existing frontend source is in the repository root.

- Stack: React, TypeScript, Vite.
- Scope: responsive dark/gold arcade interface, original fantasy artwork direction, game cards and educational probability demonstrations.
- State: browser-local demo credits/history/admin preferences.
- Limitations: not a real-money gaming product; no payment or cash-out. Browser-local admin is not secure authentication.
- Deploy: root Vite app on Vercel. See the root README.
