# Football & Prayer Dashboard

**Status:** Requirements recorded; complete source has not yet been imported into this repository.

## Requested scope
- Football fixtures/results for supported leagues and competitions, with API access through server-side environment variables.
- Prayer times for Jakarta and West Java, plus date/time display and optional adzan audio.
- Telegram support and Saweria support links as supplied by the project owner.
- Show data source, loading/error states, timezone, and last-updated time; never fabricate fixture data.

## Deployment
The dashboard can be a web app on Vercel. API keys must remain server-side.
