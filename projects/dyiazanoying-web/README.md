# DyiazAnoying Web / DyiazFitur

**Status:** Requirements gathered; complete source has not yet been imported into this repository.

## Requested scope
- Indonesian and English interface, polished responsive design, guest access and optional account flow.
- Media link tools for supported TikTok, Instagram, Pinterest and YouTube workflows, subject to provider terms.
- Username/password generation, QR, UUID, JSON, text and image utilities; Brat-style sticker maker.
- Gemini and RapidAPI integrations only through server-side routes.
- API keys stored in server environment variables, never hardcoded into frontend source.
- Keep a clear project identity and credit the supplied assets as requested.

## Deployment target
Deploy the web frontend on Vercel; use server-side functions or a separate backend for API calls. Add an environment example with placeholder names only after actual integrations are imported.
